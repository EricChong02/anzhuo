# 小E · 钉钉机器人设计

> 2026-10-25 定稿。机器人用钉钉自建团队“一起工作吧！”里的应用“小E”（Stream 模式）。第一期已实现，见 README。

## 0. 一句话目标

人不在 Mac 前，也能在钉钉里给 Mac 上的 Claude Code 派活、看它做了什么、在它等你拍板时几十秒内定下来。不只做课，任何文件夹里的事都可以。

**钉钉和网页怎么分工（2026-10-25 定：方案 C，两边都能聊）**

| | 钉钉（手机，几分钟瞄一眼） | 网页（iPad Safari，经 Tailscale，深干一小时以上） |
|---|---|---|
| 擅长 | 找到你：推送“等你定 / 做完了 / 出错了”；几秒钟拍板；发截图和语音 | 坐下来细看：所有对话一列排开、长报告、并排样稿、完整过程、试课 |
| 对话 | 同一个对话两边都能接着聊（都存在 Claude Code 自己的目录里）；同一时刻只在一边发 | 同左 |

先做钉钉这半边，再补网页这半边。网页这半边优先考虑在已审过的 claudecodeui 上补，不够再自己做。

**2026-11-04 决定**
- 钉钉整个停用，只用网页（`dingtalk = false`）。
- 网页分两个账号：admin（原来的全部功能，外加“管理”页：两个账号的登录设备、停用 / 改密码，每天和每个对话的消耗）；user（只在 `~/remote-window` 里，命令跑在沙箱里，读写不到文件夹外面、连不上本机端口，不用 GPT、定时、试课、历史记录；看不到 admin 的对话，反之亦然）。
- 消耗按 Claude 报的“按 API 标价折算的金额”比较对话（Claude 报的是会话累计，每轮记差值），同时记当时的 5 小时 / 本周额度 %。管理页只显示 tokens 和“占主账号周额度 %”，金额只用来换算。
- 换算比例 = 周额度 % 的涨幅 ÷ 同期本机全部 Claude Code 的消耗（`localspend.py` 增量读 `~/.claude/projects` 的 token 数按标价折算，远窗的和电脑上直接用的都算；周 % 读数来自每轮记录和每 10 分钟的定时读取），看最近约 4 周。claude.ai 网页版、App 的用量看不到，所以仍略偏保守。user 的周上限 = 主账号周额度 × 1/5，用同一比例换算。

## 1. 用起来是什么样（四个场景）

1. **课间派活**：在钉钉里说“在课程根新开一个：按剧本做第 2 课小节 3”，配一张剧本截图。机器人回一张任务卡，卡上的进度随它干活实时更新。你放下手机去上课。
2. **路上收到“等你定”**：手机弹出“等你定 · 第 2 课小节 3 · 封面标题放哪”，下面是两张样稿和它的推荐。你点“B”，或者引用这条消息，说一段语音“B，标题再大一点”。它接着干。
3. **沙发上深干**：收到“做完了”的报告，从头读一遍它做了什么。点里面的“试课”链接，在 iPad 上全屏点一遍；有问题就截一块图配语音发回去。
4. **不做课的事**：说“在 Projects 新开一个：把下载文件夹里这周的 PDF 按科目整理”，和做课一样派、一样收报告。

## 2. 你在钉钉里看到的消息

只有四种。每个任务一张**任务卡**，进度在卡里原地更新，不刷屏。

| 消息 | 什么时候来 | 会不会响 |
|---|---|---|
| 任务卡 | 派活后立刻来，干活时原地更新“正在做哪一步” | 只在开始时响一次 |
| 等你定 | 它需要你拍板 | 响 |
| 做完了 | 一轮活干完 | 响 |
| 出错了 | 卡住、报错、被护栏拦下 | 响 |

### 2.1 “做完了”报告（按你定的顺序）

```
【做完了】#7 课程根 · 第2课 小节3        用时 23 分钟

要你做的
· 在 iPad 上试一遍第 3—4 屏的互动（链接在下面）
· 没有要你拍板的事

2. 第 4 屏的题从选择题改成填空题（剧本里写的是“让学生自己写出来”）
3. 跑了课程检查 G1，通过
4. 按机房尺寸截图自查，发现第 3 屏说明文字偏小，已从 14 号调到 16 号

改了哪些
· 第 3 屏：标题、说明文字、配图位置
· 第 4 屏：题型和判分规则
· 教案：补了第 4 屏的设计意图

自查结果
· 课程检查 G1：通过
· 机房视口截图：4 张，见下
· 没做的：没有在真实机房核对

截图（4 张）
[第3屏] [第4屏] [第4屏答对] [第4屏答错]

试课：iPad 打开 → http://mac.你的tailscale名/preview/…
完整过程：http://mac.你的tailscale名/s/7
```

- “改了哪些”用你看得懂的话写，不列文件名。想看文件级改动，点“完整过程”。
- 两个链接只有登录了你 Tailscale 的设备打得开。
- 不是做课的任务，同样按这五段写，只是没有“试课”链接。

### 2.2 “等你定”卡

```
【等你定】#7 课程根 · 第2课 小节3

封面标题放哪？
[A 居中的截图]  [B 左下的截图]
推荐 B：画面主体是一张照片，标题放左下不挡人物。

已经做到：第 1—2 屏完成，停在第 3 屏封面。

   [ 选 A ]   [ 选 B ]   [ 都不好，我说 ]
```

- 点按钮就算定了，它马上接着干。
- 点“都不好，我说”，或者直接引用这张卡回复（文字、语音、截图都行），你的话会交给这个对话。
- 能用并排样稿让你挑的，就不让你用文字描述。

## 3. 你怎么跟它说话

- **直接发**：发给“当前对话”，也就是你最近一次派活或回复的那个。
- **引用某条消息再回复**：发给那条消息所属的对话。并行开好几个时就靠这个，不用记编号。
- **截图**：直接发图，会和你下一句话一起交给它。
- **语音**：先用 iPhone 键盘上的麦克风听写，说完变成文字再发，最稳。直接发钉钉语音消息能不能拿到转好的文字，待核实（第 9 节）。
- **几个固定说法**（也可以用自然语言说）：

| 说法 | 作用 |
|---|---|
| `新开 <文件夹> ：<要做的事>` | 在那个文件夹开一个新对话，马上开干 |
| `列表` | 所有对话：编号、文件夹、正在做 / 等你 / 做完 / 出错、最后一句 |
| `切到 7` | 之后直接发的话都给 #7 |
| `停 7` | 让 #7 停下手里的活 |
| `接着 <桌面端对话名>` | 接上桌面端里开过的某个对话，在钉钉里继续 |

## 4. 对话和文件夹（不只做课）

开对话时文件夹有五种说法（第一期已实现）：现有文件夹（短名 / 完整路径）、多个文件夹（第一个为主，其余经 add_dirs 可读写）、记不清名字（在 Projects、桌面、文稿、下载里按名字找，跳过 `_原始私密`、`.git`、依赖目录；一个就直接用，几个就列编号让你选）、不要文件夹（`~/Projects/_scratch/小E/日期-编号`）、新建文件夹（`新建 位置/名字：…`）。


- 任何文件夹都能开对话。常用文件夹给个短名，比如：`课程根` = `CyberScope-courses-zy`，`平台` = CyberScope 仓库，`Projects` = 整个工作区，`下载`。短名表放在 Mac 上的配置里，随时加。
- 每个对话自动有一个标签，例如“#7 课程根 · 第2课 小节3”。名字由第一句话生成，可以改。
- 最多同时 3 个对话在干活，再多的排队，任务卡上写“排队中”。
- 对话存在 Claude Code 自己的目录里。桌面端、命令行、钉钉三边都能接着聊，只是同一个对话别在两边同时发。

## 5. Mac 上怎么跑

```
iPhone / iPad 钉钉
      │
钉钉服务器（Mac 主动连上去，不用公网地址、不开端口）
      │
Mac：钉钉桥（开机自动启动，崩了自动重启）
      ├─ 每个对话 = 一个 Claude Code（官方 Agent SDK，用你自己的登录）
      │    · 加载和桌面端一样的规则、Skill、护栏；权限同桌面端
      │    · 额外交给它三样工具：请你定（发等你定卡）、发图、更新进度
      │    · 额外交代一条：每轮结束按第 2.1 节五段写报告
      └─ 一个小网页（只经 Tailscale）：完整过程页、试课预览转发
```

- **做课预览**：用隔离的预览后端（不碰 8000），经 Tailscale 只开给你的设备。平台代码不改。
- **“请你定”怎么来**：是交给远程对话的一个工具，Claude 判断需要你拍板时调用它。这只是钉钉桥给远程对话的额外说明，**不改做课 Skill**，所以不碰课型层。以后想让桌面端也这样，再另外商量。
- **技术选型**：Python（你 Mac 上已有，CyberScope 也是 Python），钉钉官方 Stream SDK，Claude 官方 Agent SDK。代码预计一千行上下。

## 6. 安全和学生数据

- **只认你一个钉钉账号**：别人发消息一律不理，并记一笔。
- **钉钉应用的密钥**存在 Mac 钥匙串里，不写进任何仓库或文件。
- **权限同桌面端**，意味着拿到你钉钉的人就能让 Mac 做任何事。手机丢了的处理：在钉钉里把其他设备踢下线；在电脑上把钉钉桥停掉（双击一个“停用”脚本）。
- **不替换学生姓名**（2026-10-25 庄毅定）：消息原样发到钉钉，不做姓名、学号替换。
- **只连两处外网**：钉钉和 Anthropic。不装插件，不自动更新。

## 7. 和现成工具 cc-connect 比

[cc-connect](https://github.com/chenhg5/cc-connect) 是开源的“聊天软件 ↔ 本地 Claude Code”桥，支持钉钉，很活跃（今天还有提交）。我只看了说明，没审代码。

| | cc-connect | 自己做 |
|---|---|---|
| 今天能不能用 | 能，配置完就能聊 | 第一期约 2—3 天 |
| 多对话 | 有，但一个聊天窗口一次只对着一个对话，靠 `/switch` 切 | 并行干活，引用哪条就回哪个 |
| 做完 / 等你定的推送 | 没看到专门的做法 | 核心功能 |
| 带按钮、带样稿的“等你定”卡 | 没有 | 有 |
| 实时更新的任务卡、完整过程页、试课链接 | 没有 | 有 |
| 学生数据拦截 | 没有 | 有 |
| 换文件夹 | 有（`/dir`） | 有 |
| 体量与审查成本 | 大：13 个聊天平台、10 多种 AI 工具，Go 写的，说明里有不少广告赞助 | 小，只做你要的 |
| 个人微信 | 说明里写支持（叫 ilink），未核实 | 不做 |

**我的建议**：自己做。你要的核心是“并行派活 + 做完和等你定会推给你 + 几十秒拍板”，cc-connect 的设计重心是“在聊天里对着一个对话来回聊”，补这些等于大改它。

## 9. 动手前要核实的（查文档或实测）

- 钉钉机器人收到语音消息时，有没有转好的文字。
- 引用回复时，机器人能不能知道你引用的是哪条消息（第 3 节靠这个；不行就改成卡片上放“回复这个”按钮）。
- 单条 Markdown 消息能放多长、能放几张图；放不下就把截图拆成第二条。
- 卡片按钮回调要开通哪些权限，个人建的组织能不能开。
- 个人在自己 Mac 上用订阅账号跑 Agent SDK：按 Anthropic 目前的说法属于允许的个人本地使用，开工前再看一眼官方条款。

## 回复朗读（2026-10-31）

用户点回复的小喇叭才生成；Mac 本地推理，手机只播放。2026-10-31 同文对比后，按用户“不带明显地域口音”的要求，默认音色改为 Qwen3-TTS 0.6B 8bit 的 Serena；不继续使用小贝。正文清理 Markdown、代码、网址和路径后忠实朗读，不自动改写成播客。单一播放器跨对话保留，暂停续听、倍速、前后跳、下载；生成时连续输出 MP3，完成后文件支持 Range 定位。语音环境隔离，模型按需加载、闲置十分钟释放。

音频缓存从最近一次使用起保留七天、上限 1 GiB、最久没听优先删除；不清理生成中和正在播放的音频，无可回收空间时拒绝生成。删除对话同步删除对应缓存，文字保持原有生命周期；下载的音频不受缓存清理影响。系统媒体控制接入后，仍以 iPhone 真机锁屏和主屏幕模式验收为准。

同文对比发现 Kokoro 的长中文段落可能超过 510 音素后被静默截断。文本分段改为 80 字，Kokoro 对照 / 后备路径还按 480 音素预算递归切分，禁止以截断代替分段。更换默认引擎同时更新音频缓存版本；用户之前听到的小贝缓存不会被重新当作新声音播放。

2026-10-31 用户试听后指定改为 Vivian，默认中文音色及安装试听同步切换，缓存版本单独更新，避免复用 Serena 音频。

2026-10-31 排查“长时间不播放”：关闭前端播放器后，后台旧长文未取消，曾使首段等待约 58 秒。增加按播放器请求标识的订阅与取消；最后一位听众关闭时取消未完成生成，仍有其他听众则保留。关闭先到时短期记录作废请求，迟到的开始请求不得复活。页面心跳失联且无音频传输时回收生成。界面区分排队、准备、生成与缓冲，真实播放前不标为播放中；忽略旧媒体源的迟到播放错误。

2026-10-31 用户不喜欢 Vivian，要求换成之前提到的成熟男声。默认音色与安装试听切换为中文 Uncle_Fu，同步更新缓存版本，避免播放旧女声音频。

# iPhone 随手交给远窗

三条私人快捷指令共用现有的分享凭据，通过 HTTPS 上传；不需要安装 Android APK。

- **分享给远窗**：在照片、文件或其他 App 选中内容后，从分享菜单运行。支持一次发送多个文件。
- **语音交给远窗**：从快捷指令、主屏幕或操作按钮运行，选择任务后口述要求；无需分享文件。
- **截图交给远窗**：从照片选择截图，选择任务并补充现象。图片作为参考资料交给所选对话。

先输入或口述要求，再在确认菜单点“发送”；默认新开对话并自动选择模型。模型、任务模板和目标对话按需修改，改完回到确认菜单，不会立刻发送。语音先开始听写，点停止后显示识别文字，可选择“修改要求”修正。新开时可选择自动、Opus、Sonnet、Haiku、GPT；自动沿用远窗分工表。已有任务按最近 20 个对话选择。补充已有对话沿用原模型，已接力的旧编号会转到最新一段，忙时复用原有插话或排队机制。只列出主账号的未隐藏对话。

任务模板包括总结与待办、拟回复、工作记录、截图排查、自定义要求。原资料不会被当成操作指令；未明确的信息应保留为待确认。语音空白或没有收到素材的请求不会启动任务。

发送后在同一份接收回执里显示收到的文件数量、对话编号和实际登记模型，可选“查看对话”或“完成”。回执表示接收成功，处理结果仍到对话里看。打开链接仍需正常网页登录；首次登录后也保留目标对话。

## 安装与手机设置

1. 在 iPhone 打开已签名的 `.shortcut` 文件，添加三条指令；老的“完整版”“选模型”可自行移除，避免菜单混淆。
2. 在“快捷指令”打开“分享给远窗”的详情，确认“在共享表单中显示”。
3. 第一次使用时允许连接自己的远窗域名；语音和截图还需要系统请求的麦克风、语音识别或照片访问权限。
4. 常用入口可加到主屏幕。支持操作按钮的 iPhone 可在“设置 → 操作按钮 → 快捷指令”选择“语音交给远窗”；也可在“设置 → 辅助功能 → 触控 → 轻点背面”选指令。
5. 手机上分别试一次两张截图、一次语音、新开任务和补充已有对话，核对回执与真实附件。微信的聊天导出入口和交出的内容由微信决定，不能据服务端测试保证它支持。

快捷指令包含私人上传凭据，请勿公开转发。接收入口保持向后兼容；旧版仍可继续使用。新版需服务升级并重启生效后使用。

## 重新生成

```sh
.venv/bin/python scripts/make_ios_shortcuts.py --base https://你的域名 --output-dir /本机私人目录
shortcuts sign --mode anyone --input /本机私人目录/分享给远窗.unsigned.shortcut --output /本机私人目录/分享给远窗.shortcut
```

另外两条同样签名。生成脚本从数据目录读取令牌，不会打印令牌，不把带凭据的文件放进仓库。API 新增 `GET /_x/q/<token>/options`（无缓存的选项列表），原 POST 新增 `model`、`template`、`target` 表单字段。多文件通过单个 multipart 请求一次提交，带这些选项时不支持旧版的逐文件 batch 合并。

验证记录见提交说明。自动化测试与 Mac 上签名成功不等于 iPhone 原生动作、分享扩展和权限弹窗已实测。

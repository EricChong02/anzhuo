# iPhone 随手交给远窗

正式保留三个入口：交代远窗、分享给远窗、截图交给远窗。交代远窗只唤起主屏幕远窗 App，不含上传凭据；另外两条通过现有私人凭据经 HTTPS 上传。

- **分享给远窗**：在照片、文件或其他 App 选中内容后，从分享菜单运行。支持一次发送多个文件。
- **交代远窗**：推荐绑定 iPhone 操作按钮。按住按钮唤起主屏幕远窗，并请求打开新任务页，点输入框，在微信输入法上启动语音输入，核对文字后发送。快捷指令不自动启动微信语音，也不使用 Apple 听写；打开页面本身不会创建对话或发送任务。
- **截图交给远窗**：从照片选择截图，选择任务并补充现象。图片作为参考资料交给所选对话。

分享和截图入口先输入要求，再在确认菜单点“发送”；默认新开对话并自动选择模型。模型、任务模板和目标对话按需修改，改完回到确认菜单，不会立刻发送。“交代远窗”使用普通网页输入框，方便使用熟悉的第三方输入法，模型和发送方式沿用网页。新开时可选择自动、Opus、Sonnet、Haiku、GPT；自动沿用远窗分工表。已有任务按最近 20 个对话选择。补充已有对话沿用原模型，已接力的旧编号会转到最新一段，忙时复用原有插话或排队机制。只列出主账号的未隐藏对话。

任务模板包括总结与待办、拟回复、工作记录、截图排查、自定义要求。原资料不会被当成操作指令；未明确的信息应保留为待确认。没有收到素材或有效要求的请求不会启动任务。

发送后在同一份接收回执里显示收到的文件数量、对话编号和实际登记模型，可选“查看对话”或“完成”。回执表示接收成功，处理结果仍到对话里看。所有指令的打开动作统一使用主屏幕 App 入口，分享和截图成功后用返回的对话编号请求定位，不打开普通 HTTPS 链接或 Safari。需先在主屏幕远窗中登录；iOS 是否传递具体页面位置仍需真机确认。

## 安装与手机设置

1. 在 iPhone 打开已签名的 `.shortcut` 文件，添加三个正式入口；老的“完整版”“选模型”和 Apple 听写版“语音交给远窗”可自行移除，避免菜单混淆。
2. 在“快捷指令”打开“分享给远窗”的详情，确认“在共享表单中显示”。
3. 第一次使用时允许连接自己的远窗域名；截图还需要照片访问权限。微信输入法语音的授权和开启方式由该输入法管理。
4. 常用入口可加到主屏幕。支持操作按钮的 iPhone 可在“设置 → 操作按钮 → 快捷指令”选择“交代远窗”；也可在“设置 → 辅助功能 → 触控 → 轻点背面”选指令。
5. 手机上分别试一次两张截图、一次语音、新开任务和补充已有对话，核对回执与真实附件。微信的聊天导出入口和交出的内容由微信决定，不能据服务端测试保证它支持。

快捷指令包含私人上传凭据，请勿公开转发。接收入口保持向后兼容；旧版仍可继续使用。分享与截图新版需服务升级并重启生效后使用；“交代远窗”唤起已安装的主屏幕 App，无需服务重启。

## 重新生成

```sh
.venv/bin/python scripts/make_ios_shortcuts.py --base https://你的域名 --output-dir /本机私人目录
shortcuts sign --mode anyone --input /本机私人目录/分享给远窗.unsigned.shortcut --output /本机私人目录/分享给远窗.shortcut
```

另外两条同样签名。生成脚本从数据目录读取令牌，不会打印令牌，不把带凭据的文件放进仓库。API 新增 `GET /_x/q/<token>/options`（无缓存的选项列表），原 POST 新增 `model`、`template`、`target` 表单字段。多文件通过单个 multipart 请求一次提交，带这些选项时不支持旧版的逐文件 batch 合并。

修正版说明：iPhone 实测发现条件比较参数未被正确导入，现将比较文字改为原生文本封装，并显式指定文字与数值类型，增加生成器回归测试；重新签名的修正版仍需手机运行确认。桌面 App 新建试用入口额外带上 `#new`，页面在唤醒或地址变化时也会识别；iOS 是否将此片段传给已安装 App 仍待真机确认。普通唤醒不会自动新建，已有新建草稿不会清空。

2026-11-13 入口统一：默认生成的三条和兼容语音分支，凡是打开远窗都使用 `webapp://`，不设置 Safari 降级。上传和选项请求仍走 HTTPS。主入口请求 `#new`；回执中的“查看对话”根据 `num` 构造 `#s编号`，不再使用普通网页登录链接。需要用户安装新版指令；此前“试用”“修正版”等旧条目不会自动更新。具体路由片段是否传入仍待 iPhone 验证，不把 App 已唤起等同于指定页面已打开。

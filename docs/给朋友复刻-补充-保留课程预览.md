# 补充：课程预览要保留（接在原来那段话后面发给 Codex）

---

补充一条，**改掉我前面第 1 条里“试课预览不要”那半句**：试课预览要保留，而且是这套系统对我最重要的功能之一。

我是纪丽丽，在做自己的 CyberScope 课。我的课在自己的课程根里（比如 `D:\我的课`），用 Codex 打开课程根做课，平时双击平台目录里的 `做课.cmd` 在电脑上预览。我希望出门时用手机也能预览：Codex 改完某节课，手机上直接点一个“试课”按钮，就能像在电脑上一样逐屏看。

**保留并改成适合我的：**

- 源码里的预览转发（`web.py` 的 `_proxy`、`preview_allowed`、`course_previews`，配置里的 `preview_upstream`、`preview_root`，网页里对话旁边的“试课”按钮）整套保留。
- `preview_root` 填我的课程根；`preview_upstream` 填我电脑上 `做课.cmd` 起的平台地址。**文档里写的是 Mac 的 8000，我这边 `做课.cmd` 默认是 8100**，以实际为准。我的电脑如果装了“开始上课”，入口和端口可能不同，开工前先问我、再到电脑上实测。
- Codex 改到课程根里某门课的文件后，这一轮的结果里要自动出现这门课的“试课”链接，点开是 `/studio-preview.html?course=<这门课的 course.json>`，在手机上能用“老师讲课”模式点“下一步”逐屏看。
- 课上架后从 `_drafts` 挪进 `topics`，旧链接要能自动跳到新位置（源码里 `_moved_course` 就是做这个的）。
- “反馈这一屏”（`feedback.js`）：如果不依赖 Claude 和 Mac，就保留，让我在手机上看到哪一屏不对，可以直接把意见交给 Codex 改；依赖了就先去掉，别为它卡住进度。

**不能动的底线：**

- 预览只放行预览页、课件文件和少数只读接口（设计文档安全表里“预览转发泄露数据”那条）。教师台、学生数据、WebSocket、课程库页都不转。不要为了方便把白名单放宽。
- CyberScope 平台本身是庄毅在维护的，装在我电脑上只给我做课用。你只读它、转发它，**不要改平台目录里的任何文件**，也不要读写它的数据库和钥匙。平台缺什么功能，写进我课程根里的 `给平台维护者的需求.md`，由我转给庄毅。
- 课程根里的规则（`AGENTS.md`）和写入护栏（`.codex/hooks.json`）照旧生效，案头里的 Codex 也要遵守。派活的工作文件夹就选我的课程根。
- 手机上的预览要先通过案头的登录，不能直接对外网开放 8100。

**验证（做完这一步让我亲手试）：**

1. 电脑上双击 `做课.cmd`，确认能在电脑浏览器里打开我的某门课预览。
2. 在案头里派一句话，比如“把第 1 课第 1 节的标题改成 X”，完成后结果里应该出现“试课”按钮。
3. 用手机点开“试课”，能看到这门课，点“下一步”能逐屏翻，右边的提词能看到。
4. 手机直接打开 `教师台`、`学生数据` 相关地址，应该被拒绝（显示“这个地址不开放”）。
5. 关掉 `做课.cmd` 后再点“试课”，应该提示“本机的课程预览没开”，而不是白屏。

**两个提醒：**

- 我的 `做课.cmd` 窗口必须开着，手机才看得到预览。这点要在页面提示里写清楚。
- 源码里预览相关的路径（`/workspace/`、`/courses/`）是对着 Mac 上那版 CyberScope 写的。我电脑上的版本可能有差异，**以实测为准**，不一致就告诉我，别硬套。

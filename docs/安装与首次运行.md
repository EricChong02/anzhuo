# 安装与首次运行

这一篇带你从零把案头装好，一步一步，每一步都写了“应该看到什么”。全程大约 10 分钟。

## 0. 先确认几件事

| 需要 | 说明 |
|---|---|
| 一台 Mac | 目前只在 macOS 上验证过（密钥放钥匙串、开机自启用 launchd、插电时防睡眠用 `caffeinate`）。Linux / Windows 没有验证 |
| [uv](https://docs.astral.sh/uv/) | Python 包管理器，会自动装好 Python 3.13+。没有就先 `brew install uv`，或照官网一行命令装 |
| Claude 账号 | 订阅账号即可（案头用官方的 Claude Agent SDK 干活）。**费用 / 额度算在你自己的账号上** |
| （可选）ChatGPT 桌面版 | 想让对话也能用 GPT（Codex）干活才需要：装好并登录。位置固定在 `/Applications/ChatGPT.app` |
| （可选）钉钉 | 想在钉钉里也能指挥才需要，见 [钉钉接入](钉钉接入.md)；不用就完全不用管 |

> 只想先看看界面？不用装任何账号，直接跑演示模式：`.venv/bin/python scripts/demo.py`（装完依赖后），浏览器打开 http://127.0.0.1:8799 ，账号 `demo`，密码 `demo`。里面是虚构的对话，不连 AI、不碰你的任何东西。

## 1. 下载代码、装依赖

```bash
git clone https://github.com/EricChong02/anzhuo.git
cd anzhuo
uv sync
```

应该看到 `uv` 创建了 `.venv` 并装好若干包。完成后 `.venv/bin/anzhuo` 这个命令就有了。下面的命令都在仓库根目录里运行。

## 2. 放好配置文件

```bash
mkdir -p ~/.config/anzhuo
cp config.example.toml ~/.config/anzhuo/config.toml
```

示例配置里**每一项都是注释掉的**——也就是说，不改也能用：网页默认开在本机 `http://127.0.0.1:8765`，不用钉钉，危险命令都等你点头，不会自动清理任何东西。以后想调什么，翻 [配置参考](配置参考.md)。

想把配置放在别处？设环境变量 `ANZHUO_CONFIG=/路径/config.toml`（数据目录同理：`ANZHUO_DATA`）。

## 3. 给案头登录一次 Claude

```bash
scripts/claude_login.sh
```

会打开浏览器让你授权。案头用的是 Claude Agent SDK 自带的那份 Claude Code，和你平时在终端里用的是**两份登录状态**，所以这里要单独登一次。登一次就行，之后不用再管。

应该看到类似 `Logged in` 的状态输出。

## 4. 设置网页登录的账号和密码

```bash
.venv/bin/anzhuo passwd
```

按提示输入账号、密码、再输一遍。**密码本身不会保存**，只把它的 PBKDF2 指纹存进 macOS 钥匙串（服务名 `anzhuo.web`），账号写进配置文件的 `web_user`。

> 这是挡在“任何能打开这个网页的人”和“你的电脑”之间的唯一一道门。请用一个强密码，不要和别处共用。

## 5. 自检

```bash
.venv/bin/anzhuo check
```

应该看到类似：

```
配置：/Users/你/.config/anzhuo/config.toml
文件夹短名：（没配，网页里选“临时文件夹”或手输路径也能用）
网页：http://127.0.0.1:8765，登录账号 你设的账号
钉钉：没开（配置里没有 client_id），只用网页
Claude：已登录（…）
数据目录：/Users/你/.local/share/anzhuo
```

哪一行报问题，就按它的提示处理（比如“账号在钥匙串里没有密码”→ 重新运行 `anzhuo passwd`）。全部没问题时命令的退出码是 0。

## 6. 前台运行，试一次

```bash
.venv/bin/anzhuo run
```

浏览器打开 http://127.0.0.1:8765 ，用刚才的账号密码登录，点左上角的铅笔图标（新对话）：

1. 输入框下面有一个小按钮，写着“在哪做”：这就是这个对话的**工作文件夹**。第一次可以选“临时文件夹”（一个空的临时目录，不碰你的任何文件），或者在菜单最下面的输入框里粘贴一个项目路径，比如 `~/Projects/my-app`；
2. 写一句话，比如“列一下这个文件夹里有什么”，发送；
3. 应该看到：对话出现在左边“在做”里，右边有一行正在做的步骤和进度条；做完后给出回复。

到这里案头就是通的。按 `Ctrl+C` 停掉前台进程。

> 从第二次起，新对话的文件夹默认就是你上次用的那个，“最近用过的”会列在菜单最上面。常用文件夹也可以在配置的 `[folders]` 里起个短名，见 [配置参考](配置参考.md#folders)。

## 7. 开机自启、崩了自动重启

```bash
scripts/install_launchd.sh
```

它会写一个 launchd 配置 `~/Library/LaunchAgents/local.anzhuo.plist` 并启动。之后：

- 开机（登录后）自动运行；崩了 30 秒后自动拉起；
- 日志在 `~/Library/Logs/anzhuo/`（`out.log`、`err.log`）；日志**只记消息类型和长度，不记内容**；
- **改了代码或配置后，再运行一次这条命令**就会用新的重启；
- 想停掉：双击 `scripts/停用案头.command`（会同时取消开机自启）。

另外，案头运行时会在你插着电的情况下阻止 Mac 睡眠（`caffeinate -s`，案头一退出就自动失效）；合上盖子或用电池时照常睡眠。Mac 睡着了，手机上就连不上它——这是正常的。

## 8. 如果你要让它读“下载 / 桌面 / 文稿”里的文件夹

macOS 对这三个文件夹有隐私保护。案头在后台（开机自启）头一次用到它们时，系统会弹窗问“允许吗”，**没人点就会一直卡着**。案头会先试 5 秒，打不开就直接告诉你，不会干等。授权一次即可：

1. 系统设置 → 隐私与安全性 → 完全磁盘访问权限，点左下角“+”；
2. 按 `Cmd+Shift+G`，粘贴案头所用的 Python 路径——先用这条命令查：
   ```bash
   .venv/bin/python -c "import sys,os; print(os.path.realpath(sys.executable))"
   ```
3. 选中打开，并确认开关打开；
4. 重新运行 `scripts/install_launchd.sh` 让案头重启。

`uv` 以后升级了 Python 版本，这个路径会变，需要按新路径再加一次。

## 9. 想从别的设备用？

到这里这台电脑上能用了。想让手机、iPad、别的电脑也能用，需要一条通路，并且**要你自己准备一台服务器做中转**，见 [外网访问](外网访问.md)。想在钉钉里指挥，见 [钉钉接入](钉钉接入.md)。

## 更新

```bash
git pull
uv sync
scripts/install_launchd.sh   # 用新代码重启
```

数据都在案头自己的数据目录里，更新不会丢对话。

## 卸载

```bash
scripts/停用案头.command                         # 停掉并取消开机自启（也可以在访达里双击）
rm -rf ~/.config/anzhuo ~/.local/share/anzhuo    # 删除配置和案头自己的记录
security delete-generic-password -s anzhuo.web -a 你的网页账号      # 删除钥匙串里的条目（按需）
security delete-generic-password -s anzhuo.webpush -a vapid
security delete-generic-password -s anzhuo.dingtalk -a 你的ClientID  # 用过钉钉才有
security delete-generic-password -s anzhuo.deepseek -a api           # 配过 DeepSeek 才有
```

> 删除 `~/.local/share/anzhuo` 只会删掉案头自己记的“编号 ↔ 对话”对照表、过程记录和收发过的文件副本；**对话内容本身存在 Claude Code / Codex 自己的目录里**（`~/.claude`、`~/.codex`），不受影响。

用法与页面
HOW

三步用起来，
之后全在手机上。

1
在电脑上装好

需要 Mac、uv 和一个 Claude 账号。几条命令，十分钟，命令见最后一页。

2
手机上说一句话

选工作文件夹（上次用的默认选中），写要做的事。它在你的电脑上开工，进度实时可见。

3
需要你时点一下

选方案、批准危险命令、收文件，都是按钮。做完弹通知，没事就不打扰。

派活选文件夹：最近用过的、常用短名、临时文件夹，或手输路径。
看进度一步一格的进度条，随时插话或停止，点开看完整过程。
点一下它列出方案和推荐，选项变成按钮，点了就接着做。
电脑端左边按“需要你 / 在做 / 新完成”分组，右边是对话；同一套界面，手机电脑通用。

DOOR 01登录是第一道门

PBKDF2 密码指纹；同一来源错 5 次锁 15 分钟；写接口校验同源；设备可逐台退出。

DOOR 02危险命令先问你

git push、rm、sudo 等先停下，等你点“允许”；可选 AI 审核员，默认关。它是安全带，不是沙箱。

DOOR 03不预先授权任何事

提交、推送、部署都会问你；想少问，你自己写进配置，后果自己清楚。

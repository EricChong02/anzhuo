用法与页面
HOW

三步用起来，
之后随处可用。

1
在电脑上装好

家里的 Mac 装远窗（需要 uv 和 Claude 账号），再准备一台自己的服务器做中转。命令见最后一页。

2
在任何设备上说一句话

选工作文件夹（上次用的默认选中），写要做的事。它在你的电脑上开工，进度实时可见。

3
需要你时点一下

选方案、批准危险命令、收文件，都是按钮。做完弹通知，没事就不打扰。

派活 · iPhone选文件夹：最近用过的、常用短名、临时文件夹，或手输路径。
看进度 · iPad一步一格的进度条，随时插话或停止，点开看完整过程。
点一下 · iPhone方案变成按钮，点了就接着做。
电脑浏览器左边按“需要你 / 在做 / 新完成”分组，右边是对话；和 iPad、手机是同一套界面。

对话内容 存在 Claude / Codex 自己的目录，桌面端、命令行、手机能接着聊同一个对话
密钥 只在 macOS 钥匙串：网页密码指纹、钉钉密钥、推送私钥
远窗自己的记录 对话编号表、每轮过程、收发的文件，都在本机数据目录
要自备一台服务器。远窗不提供中转服务，作者自己的服务器也不对外开放。你的访问设备不需要代理、不装软件，只要家里那台 Mac 连得上 Claude / GPT。（不想买服务器也可用 Tailscale / Cloudflare，各有取舍，见文档。）
DOOR 01登录是第一道门

PBKDF2 密码指纹；同一来源错 5 次锁 15 分钟；写接口校验同源；设备可逐台退出。

DOOR 02危险命令先问你

git push、rm、sudo 等先停下，等你点“允许”；可选 AI 审核员，默认关。它是安全带，不是沙箱。

DOOR 03不预先授权任何事

提交、推送、部署都会问你；想少问，你自己写进配置，后果自己清楚。

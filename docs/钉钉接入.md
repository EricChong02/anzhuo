# 钉钉接入（可选）

案头默认只用网页。如果你习惯在钉钉里指挥，可以再接一个钉钉机器人：在钉钉里给它发话、收结果、点按钮；做完的报告、截图、文件都会发回钉钉。

**为什么用钉钉？** 它的“企业内部机器人”支持 **Stream 模式**——案头主动连出去，**不需要公网回调地址**，电脑不用开放任何端口，个人也能免费建一个只有自己的小团队来用。

> 钉钉是**兜底入口**：详细的过程、回退分叉、设置、定时任务管理都在网页里；钉钉里只留“直接说话”和最常用的几个指令（见 [使用指南](使用指南.md#12-钉钉里的说法)）。

## 先说清楚：能做和不能做

| | |
|---|---|
| 能 | 发文字、图片、文件（≤20MB）、语音（用钉钉转好的文字）；收做完的报告、截图、文件；点“要你定”的选项按钮、点“允许 / 不允许”按钮、点“停”按钮 |
| 不能 | 群聊（只认**单聊**）；文件超过 20MB（会提示到网页下载）；钉钉“吊顶卡片”（只支持企业群，机器人单聊用不了——案头改成每次都重发到底部的“工作台”卡） |
| 免费额度 | 钉钉接口每月 1 万次。案头默认的“安静模式”下，每件活只发结果、截图几条消息，够用 |

## 步骤

> 钉钉开发者后台的界面会改版，下面的菜单名以你看到的为准，官方文档在 <https://open.dingtalk.com>。

### 1. 建一个企业内部应用和机器人

1. 打开钉钉开发者后台，登录后选一个你是管理员的组织（没有就先建一个只有自己的小团队）；
2. 创建**企业内部应用**；
3. 给应用添加**机器人**能力，**消息接收模式选“Stream 模式”**；
4. 在“凭证与基础信息”里记下 **Client ID**（也叫 AppKey）和 **Client Secret**（AppSecret）；
5. **发布**应用（版本发布后，机器人才能在钉钉里搜到、发消息）。

### 2. 开通权限

案头会用到：机器人发送单聊消息、下载机器人收到的文件和图片、互动卡片的创建和更新。在应用的“权限管理”里把这几类开通。**不确定开哪个时，先跑起来**——缺权限时钉钉接口会返回 403，并在错误里写出缺哪项（案头日志和网页的出错提示会原样显示），照着补开即可。

### 3. 填配置、存密钥

```toml
# ~/.config/anzhuo/config.toml
client_id = "你的 Client ID"
allowed_user_ids = []          # 先空着，第 4 步查到再填
```

把 Client Secret 存进钥匙串（只在终端里输入，不显示、不进任何文件或命令记录。**这一步只在 macOS 上可用**——密钥只存 macOS 钥匙串，Windows 暂时用不了钉钉入口）：

```bash
scripts/save_secret.sh
```

脚本会读配置里的 `client_id`，然后问两次 `password data`：都粘贴 Client Secret，各按一次回车。

### 4. 查到你自己的钉钉 ID

```bash
.venv/bin/anzhuo whoami
```

看到“已连上钉钉”后，**在钉钉里给机器人发一句话**，终端会打印：

```
发消息的人：你的昵称　钉钉 ID（senderStaffId）：xxxxxxxx　会话类型：1
```

把这个 ID 填进配置：

```toml
allowed_user_ids = ["xxxxxxxx"]
```

按 `Ctrl+C` 结束 `whoami`。

### 5. 自检并重启

```bash
.venv/bin/anzhuo check          # 钉钉那一段应该显示“能拿到调用凭证”
scripts/install_launchd.sh      # 重启案头
```

在钉钉里给机器人发“帮助”，应该收到用法说明。

## 它在钉钉里是什么样

- **直接说话** → 交给当前对话（它在做事就是插话）；
- **报告**：做完后发一条标题 + Claude 回复**原文**（不改写、不删段）+ 实际改动的文件和命令，底部有用时、模型、上下文和额度；
- **“要你定”**：回复以“要你定”开头、列了 A / B / C 时，报告后会再发一张按钮卡，点“选 B”就把“选 B：……”交回那个对话，卡片变成“已选 B”；
- **危险命令确认**：一张“等你确认”的卡片，带“允许 / 不允许”；
- **工作台卡**（`dingtalk_quiet = false` 时）：所有在做的对话列在一张卡上，原地更新，每件带“停”按钮；
- 卡片用钉钉**公开的 Markdown + 按钮模板**，你不用自己建模板。卡片记录存在数据目录的 `cards.json`，重启后按钮仍有效。

## 安全

- **只认 `allowed_user_ids` 里的钉钉账号发来的单聊消息**，其余一律忽略并记日志；
- Client Secret 只在钥匙串，配置、仓库、日志里都没有；
- 记住：对话以“跳过权限确认”运行，**拿到你钉钉账号的人就能指挥这台电脑**。手机丢了先在钉钉里踢下线，再双击 `scripts/停用案头.command`。

## 排查

| 现象 | 怎么办 |
|---|---|
| `anzhuo check` 说“钥匙串里没有钉钉密钥” | 重新运行 `scripts/save_secret.sh`；账户名必须就是配置里的 `client_id` |
| 给机器人发消息没反应，日志有“忽略一条消息” | 发送人的钉钉 ID 不在 `allowed_user_ids` 里，或者你是在群里发的（只认单聊） |
| 发消息有反应但收不到图 / 文件 | 应用权限里缺“下载机器人消息文件”类的权限，补开 |
| 按钮点了没反应 | 缺互动卡片的权限；或应用没把卡片回调设为 Stream |
| 收到的报告被拆成好几条 | 钉钉单条 Markdown 有长度限制，案头自动拆分，属正常 |

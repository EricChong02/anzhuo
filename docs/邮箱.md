# 邮箱（网易 163）

小E 的对话可以直接读写 `yi_official@163.com`：列信、搜信、看正文、下附件、发信、移动/标记。工具是 `scripts/mail163.py`，只用 Python 标准库，不需要装别的。

## 一次性设置：授权码

网易不认邮箱登录密码，第三方客户端要用「授权码」：

1. 电脑浏览器登录 <https://mail.163.com>，右上「设置」→「POP3/SMTP/IMAP」。
2. 开启「IMAP/SMTP 服务」（要手机短信验证）。
3. 生成「授权码」（16 位左右，只显示一次），复制。
4. 在 Mac 终端运行下面这条，粘贴授权码（不回显），回车：

   ```sh
   security add-generic-password -U -s remote-claude.mail163 -a yi_official@163.com -w
   ```

授权码只存在钥匙串，不进仓库、不进任何文件。换授权码时重复第 4 步即可（`-U` 会覆盖）。

## 常用

```sh
M="python3 /Users/zhuangyi/Projects/04_项目/personal/remote-claude/scripts/mail163.py"

$M folders                              # 文件夹（中文名自动处理）
$M list --limit 20                      # 最近 20 封
$M list --unread --days 7               # 最近 7 天未读
$M search --from someone@x.com --days 30
$M search --subject 合同 --text 发票 --days 90
$M show 12345                           # 读正文（UID 来自 list/search）
$M show 12345 --max-chars 20000
$M attachments 12345 --out ~/Downloads/邮件附件
$M save 12345 --out ~/Downloads/邮件附件  # 整封 .eml
$M send --to a@b.com --subject 标题 --body 正文 --attach 文件.pdf
$M mark 12345 --unread                  # 标未读；不加 --unread 是标已读
$M move 12345 --to 存档                  # 移到文件夹
$M delete 12345                         # 删除
```

所有命令都支持 `--json`，方便程序处理。`--folder` 可以指定别的文件夹（如「已发送」）。

## 给小E 的约定

- 先在对话里说清楚要干什么，再动邮件；删除、批量移动前先列出清单确认。
- 读信默认不改已读状态（用 `BODY.PEEK`）。
- 附件默认下到 `~/Downloads/邮件附件`，按需换目录。
- 不把授权码打印、写文件或发给别人。

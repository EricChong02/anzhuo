# 配置参考

配置文件是 TOML 格式，默认位置 `~/.config/anzhuo/config.toml`，也可以用环境变量 `ANZHUO_CONFIG` 指定别处。改完配置后**重启案头**才生效（`scripts/install_launchd.sh`，或重新 `anzhuo run`）。

**每一项都有默认值，空文件也能运行。** 仓库里的 [`config.example.toml`](../config.example.toml) 是带注释的模板，所有项都先注释掉了。

> 钉钉应用密钥、网页登录密码这类秘密**不写在配置里**：macOS 存钥匙串（见文末“钥匙串条目”）；Windows 下网页密码指纹存配置目录旁的 `web_hash.json`，钉钉密钥暂只支持 macOS。

## 入口：网页

| 配置项 | 默认 | 说明 |
|---|---|---|
| `web` | `true` | 写 `false` 关掉网页（那就必须开钉钉，否则案头没有入口，启动会报错） |
| `web_base` | `http://127.0.0.1:<web_port>` | 网页的访问地址。本机用不用改；放到外网后改成你的 HTTPS 地址（如 `https://anzhuo.example.com`）。它决定通知里链接的写法，以及登录 Cookie 要不要带 `Secure`（只有 `https://` 才带） |
| `web_port` | `8765` | 网页只听 `127.0.0.1` 的这个端口，不对局域网和外网开放 |
| `web_user` | 空 | 网页登录账号。**不用手写**，运行 `anzhuo passwd` 会替你写进来，并把密码指纹存进钥匙串（Windows 存 `web_hash.json`） |
| `watch_host` | 空 | 可选：外网服务器的 ssh 别名。设了之后，案头会把手机通知的订阅同步一份过去，服务器上的 `scripts/server_watch.py` 才知道往哪发“案头掉线了”的通知，见 [外网访问](外网访问.md#掉线提醒可选) |

## 入口：钉钉（可选）

不填 `client_id` 就是**只用网页**，不会连钉钉。详细步骤见 [钉钉接入](钉钉接入.md)。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `client_id` | 空 | 钉钉企业内部应用的 Client ID（AppKey）。填了才开钉钉；对应的 Client Secret 存钥匙串 |
| `allowed_user_ids` | `[]` | **只认这些钉钉 ID 发来的单聊消息**，其余一律忽略并记日志。开了钉钉就必须填；用 `anzhuo whoami` 查自己的 |
| `dingtalk_quiet` | `true` | 钉钉“安静模式”：只在有结果时弹（做完 / 等你定 / 出错 / 指令回话 / 直接回答），开工、收到、插话、工作台这些过程消息只在网页里看。`false` 恢复全发 |

## folders

```toml
[folders]
项目 = "~/Projects/my-app"
笔记 = "~/Documents/notes"
```

给常用文件夹起短名：短名会出现在网页“新对话”菜单里，钉钉里也能写 `新开 项目：…`；定时任务的“工作文件夹”下拉也用它。**不配也行**：网页里有“最近用过的文件夹”和手输路径。

**注意**：`[folders]` 这个表要写在配置文件的**最后**（TOML 的规矩：写了 `[folders]` 之后的键都属于它）。`anzhuo passwd` 会把 `web_user` 插在第一个 `[` 之前，不会弄坏它。

## 文件夹查找

| 配置项 | 默认 | 说明 |
|---|---|---|
| `scratch_root` | `~/anzhuo-scratch` | “不指定文件夹”时用的临时文件夹放哪，每次新开一个 `日期-编号` 的空目录。开了 `auto_cleanup` 后，60 天没动、也没有对话在用的会被挪进废纸篓 |
| `search_roots` | `["~/Projects", "~/Desktop", "~/Documents", "~/Downloads"]` | 在网页输入文件夹名的几个字、或钉钉里写 `新开 某个词：…` 时，在这些位置里按名字找（最深 4 层，跳过 `.git`、`node_modules`、`.venv` 等）。完全相同的名字排最前，其次开头相同，再次包含 |
| `skip_names` | `[]` | 按名字找时要跳过的文件夹名（前缀匹配），比如放私密资料的 `["_private"]` |

> macOS 对“下载 / 桌面 / 文稿”有隐私保护，后台进程第一次碰它们会卡在授权弹窗上。案头会先试 5 秒、打不开就告诉你；授权方法见 [安装与首次运行](安装与首次运行.md#8-如果你要让它读下载--桌面--文稿里的文件夹)。

## 干活的方式

| 配置项 | 默认 | 说明 |
|---|---|---|
| `max_parallel` | `3` | 最多同时几个对话在干活，多的排队（列表里写“排队中”） |
| `default_effort` | 不填 | 默认思考深度：`low` / `medium` / `high` / `xhigh` / `max`。不填就用 Claude Code 自己设置里的 |
| `simple_model` | `"sonnet"` | 简单任务（查资料、整理文件、问答；文件夹里没有 `.git` / `pyproject.toml` / `package.json`）用的模型：`opus` / `sonnet` / `haiku` / `fable` |
| `dev_model` | `"opus"` | 开发类任务（文件夹看起来是个项目）用的模型 |
| `reply_language` | `"简体中文"` | 追加给每个对话的固定要求里写的回复语言（“回复一律用……”）。写成 `""` 表示不指定 |
| `extra_instructions` | 空 | **你自己的固定要求**，会追加给每个 Claude 对话（以及 Codex 对话的开场指令）。比如 `"小改动做完直接提交，不用问我。"` 这是你**主动授权**的地方，案头自己不预先授权任何事 |
| `translate_english` | `false` | **默认关闭**，不会有任何内容被送去翻译。改成 `true` 后，回复里有大段英文（连着 8 个以上英文单词，代码、命令、路径不算）时，先译成中文再给你看，包括网页“工作过程”里的英文思考。优先用 DeepSeek（便宜快，要自己在钥匙串放密钥，见下）；没有密钥就用 Haiku，这会消耗你自己的 Claude 额度。改完重启案头生效 |

话里说了“用 opus”“深度调到高”就以话里说的为准。

## 安全与整理

| 配置项 | 默认 | 说明 |
|---|---|---|
| `auto_review` | `false` | `false`：危险命令一律等你点“允许”。`true`：先交给另一个 AI 审核员（Sonnet，低档思考）判断，放行或拦下都写进这一轮的报告；它出错或超时才退回来问你 |
| `review_policy` | 空 | 开了 `auto_review` 后，你额外授权审核员放行的事，写成一段话，例如 `"推送到 dev 分支、重启开发用的服务可以放行；推送到 main 一律拦下。"` 审核员默认**不放行推送、上线、部署** |
| `auto_cleanup` | `false` | `true`：案头每天做一次整理——把 `~/.claude/projects/` 里 **90 天没动**的 Claude 对话记录压缩归档（gzip，能解开）到 `~/.claude/projects-archive/`（案头里还登记着的对话不动）；把超过 60 天没动、也没有对话在用的临时文件夹挪进废纸篓；**每个月第一次检查时**（刚启用时从下个月开始）自动开一个“清理体检”对话，只列清单，等你点头才把东西挪进废纸篓 |
| `timezone` | 空 | 定时任务用的时区，如 `"Asia/Shanghai"`。空 = 这台电脑当前的时区 |

> `auto_cleanup` 会动 `~/.claude` 里的对话记录位置，所以默认关。对话里的截图和文件副本（`inbox/`、`outbox/`）**任何情况下都不会被自动删除**。

## 环境变量

| 变量 | 说明 |
|---|---|
| `ANZHUO_CONFIG` | 配置文件路径，默认 `~/.config/anzhuo/config.toml` |
| `ANZHUO_DATA` | 数据目录，默认 `~/.local/share/anzhuo` |
| `ANZHUO_WEB_HASH` | 直接给出网页密码的指纹，**优先于钥匙串 / `web_hash.json`**（演示、测试用；指纹用 `anzhuo.web.hash_password` 生成）。一般用 `anzhuo passwd` 就行 |
| `CODEX_HOME` | Codex 的数据目录（读 Codex 的模型配置用），默认 `~/.codex` |

## 钥匙串条目

案头不把任何密钥写进配置、仓库或日志。macOS 钥匙串里它会用到这些条目（服务名 → 账户）：

| 服务名 | 账户 | 里面是什么 | 怎么放进去 |
|---|---|---|---|
| `anzhuo.web` | 网页账号 | 网页登录密码的 PBKDF2 指纹 | `anzhuo passwd` |
| `anzhuo.dingtalk` | 钉钉 Client ID | 钉钉应用的 Client Secret | `scripts/save_secret.sh` |
| `anzhuo.webpush` | `vapid` | 网页推送的签名私钥 | 第一次用到时自动生成 |
| `anzhuo.deepseek` | `api` | DeepSeek 的 API 密钥（可选，只在打开 `translate_english` 且想用 DeepSeek 翻译时才需要） | `security add-generic-password -U -s anzhuo.deepseek -a api -w`，回车后粘贴 |

## 数据目录里有什么

默认 `~/.local/share/anzhuo/`（`ANZHUO_DATA` 可改）：

| 文件 / 目录 | 内容 |
|---|---|
| `sessions.json` | 对话登记表：编号 ↔ Claude / Codex 的会话 ID ↔ 工作文件夹，以及名字、模型、状态等 |
| `turns/` | 每一轮的记录（说了什么、步骤、改了哪些文件、截图），“完整过程”页和 GPT 对话的历史靠它 |
| `inbox/`、`outbox/` | 你发给它的文件、它交给你的截图和文件的副本。**不会自动删除** |
| `web.json` | 网页登录的设备和会话（Cookie 对应的），权限 600 |
| `push.json` | 手机通知的设备订阅 |
| `schedules.json` | 定时任务 |
| `cards.json` | 钉钉卡片和按钮对应的对话（重启后按钮还能用） |
| `translations.json` | 翻译过的英文片段缓存 |
| `checkpoints/` | Codex 对话的工作文件快照（按内容哈希复用） |
| `recent.jsonl` | 最近 100 条来往原文，**只留在本机**，排查“它为什么这么答”时看 |
| `checkup.json` | 每月体检做到哪个月了（开了 `auto_cleanup` 才有） |

日志在 `~/Library/Logs/anzhuo/`，只记消息类型和长度，不记内容。

## 一份完整的示例

只用网页、放在自己服务器上、让审核员代你放行自己仓库的 dev 分支推送：

```toml
web_base = "https://anzhuo.example.com"
web_port = 8765
watch_host = "my-server"             # ~/.ssh/config 里的主机别名
max_parallel = 4
dev_model = "opus"
simple_model = "sonnet"
reply_language = "简体中文"
extra_instructions = "小改动做完后直接 git commit，提交信息用中文，不用问我。"
auto_review = true
review_policy = "推送到 dev 分支可以放行；推送到 main、强制推送一律拦下。"
timezone = "Asia/Shanghai"

[folders]
项目 = "~/Projects/my-app"
笔记 = "~/Documents/notes"
```

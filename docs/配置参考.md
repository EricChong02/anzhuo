# 配置参考

配置文件是 TOML 格式，默认位置 `~/.config/anzhuo/config.toml`，也可以用环境变量 `ANZHUO_CONFIG` 指定别处。改完配置后**重启远窗**才生效（`scripts/install_launchd.sh`，或重新 `anzhuo run`）。

**每一项都有默认值，空文件也能运行。** 仓库里的 [`config.example.toml`](../config.example.toml) 是带注释的模板，所有项都先注释掉了。

> 钉钉应用密钥、网页登录密码这类秘密**不写在配置里**：macOS 存钥匙串（见文末“钥匙串条目”）；Windows 下网页密码指纹存配置目录旁的 `web_hash.json`，钉钉密钥暂只支持 macOS。

## 入口：网页

| 配置项 | 默认 | 说明 |
|---|---|---|
| `web` | `true` | 写 `false` 关掉网页（那就必须开钉钉，否则远窗没有入口，启动会报错） |
| `web_base` | `http://127.0.0.1:<web_port>` | 网页的访问地址。本机用不用改；放到外网后改成你的 HTTPS 地址（如 `https://anzhuo.example.com`）。它决定通知里链接的写法，以及登录 Cookie 要不要带 `Secure`（只有 `https://` 才带） |
| `web_port` | `8765` | 网页只听 `127.0.0.1` 的这个端口，不对局域网和外网开放 |
| `web_user` | 空 | 网页登录账号。**不用手写**，运行 `anzhuo passwd` 会替你写进来，并把密码指纹存进钥匙串（Windows 存 `web_hash.json`） |
| `web_prefix` | 空 | 子路径挂载：被别的自托管面板反向代理**透传**（不剥前缀）时，整站挂在它下面，如 `"/yuanchuang"`；写成 `"yuanchuang"` 也行。空 = 根路径，行为与以前完全一样。此时 `web_base` 应填**面板的 origin**（协议 + 域名 + 端口，不含路径），写接口的同源校验才认得浏览器发来的 `Origin`。见 [外网访问 · 方案 D](外网访问.md#方案-d挂在已有自托管面板的子路径下) |
| `watch_host` | 空 | 可选：外网服务器的 ssh 别名。设了之后，远窗会把手机通知的订阅同步一份过去，服务器上的 `scripts/server_watch.py` 才知道往哪发“远窗掉线了”的通知，见 [外网访问](外网访问.md#掉线提醒可选) |

## 入口：钉钉（可选）

不填 `client_id` 就是**只用网页**，不会连钉钉。详细步骤见 [钉钉接入](钉钉接入.md)。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `client_id` | 空 | 钉钉企业内部应用的 Client ID（AppKey）。填了才开钉钉；对应的 Client Secret 存钥匙串 |
| `allowed_user_ids` | `[]` | **只认这些钉钉 ID 发来的单聊消息**，其余一律忽略并记日志。开了钉钉就必须填；用 `anzhuo whoami` 查自己的 |
| `dingtalk_quiet` | `true` | 钉钉“安静模式”：只在有结果时弹（做完 / 等你定 / 出错 / 指令回话 / 直接回答），开工、收到、插话、工作台这些过程消息只在网页里看。`false` 恢复全发 |

## folders

```toml
[folders]
项目 = "~/Projects/my-app"
笔记 = "~/Documents/notes"
```

给常用文件夹起短名：短名会出现在网页“新对话”菜单里，钉钉里也能写 `新开 项目：…`；定时任务的“工作文件夹”下拉也用它。**不配也行**：网页里有“最近用过的文件夹”和手输路径。

**注意**：`[folders]` 这个表要写在配置文件的**最后**（TOML 的规矩：写了 `[folders]` 之后的键都属于它）。`anzhuo passwd` 会把 `web_user` 插在第一个 `[` 之前，不会弄坏它。

## 文件夹查找

| 配置项 | 默认 | 说明 |
|---|---|---|
| `scratch_root` | `~/anzhuo-scratch` | “不指定文件夹”时用的临时文件夹放哪，每次新开一个 `日期-编号` 的空目录。开了 `auto_cleanup` 后，60 天没动、也没有对话在用的会被挪进废纸篓 |
| `search_roots` | `["~/Projects", "~/Desktop", "~/Documents", "~/Downloads"]` | 在网页输入文件夹名的几个字、或钉钉里写 `新开 某个词：…` 时，在这些位置里按名字找（最深 4 层，跳过 `.git`、`node_modules`、`.venv` 等）。完全相同的名字排最前，其次开头相同，再次包含 |
| `skip_names` | `[]` | 按名字找时要跳过的文件夹名（前缀匹配），比如放私密资料的 `["_private"]` |
| `deepseek_block` | `[]` | DeepSeek 对话不许碰的文件夹名（前缀匹配），如 `["私密"]`。DeepSeek 引擎会把对话内容发到 DeepSeek 的服务器：工作文件夹在这些文件夹里就不开工，干活中途的工具调用碰到它们也一律拒掉 |

> macOS 对“下载 / 桌面 / 文稿”有隐私保护，后台进程第一次碰它们会卡在授权弹窗上。远窗会先试 5 秒、打不开就告诉你；授权方法见 [安装与首次运行](安装与首次运行.md#8-如果你要让它读下载--桌面--文稿里的文件夹)。

## 干活的方式

| 配置项 | 默认 | 说明 |
|---|---|---|
| `max_parallel` | `3` | 最多同时几个对话在干活，多的排队（列表里写“排队中”） |
| `default_effort` | 不填 | 默认思考深度：`low` / `medium` / `high` / `xhigh` / `max`。不填就用 Claude Code 自己设置里的 |
| `[split.design]` / `[split.dev]` / `[split.simple]` | 定方案 `opus`，开发、简单任务 `sonnet` | 分工表：三档各交给谁。`use` 首选（Claude 的 `opus` / `sonnet` / `haiku` / `fable`，或别家 `gpt` / `deepseek` / `kimi`）、`model` 别家的型号（不写用它自己默认的）、`effort` 深度、`backup` 备选（首选没装、没密钥、受限账号不能用、文件夹在 `deepseek_block` 里时换它；首选那家额度**告急或撞线**、而备选那家更宽裕（或同是 Claude、换更省的型号）时也换它，只是偏紧照用首选——质量优先；不写退回 Sonnet）。额度分档按“已用多少 + 用得多快”：已用 ≥ 90% 或过半且按这速度到重置要用到 150% 算告急，已用 ≥ 75% 或按这速度重置前就会用完算偏紧。新开对话没指定模型时，代码仓里按开发档挑，别处按简单任务档。网页 管理 · 设置 里能改。老写法 `simple_model` / `dev_model` / `design_model` 仍然认 |
| `subagent_model` | `"sonnet"` | Claude 对话里派出去的子代理默认用的模型（设成环境变量 `CLAUDE_CODE_SUBAGENT_MODEL`）。写 `""` = 不另指定，跟主对话一样 |
| `relay_long` | `120000` | 上下文到这么多 token 就提示“接力到新对话”：每说一句都要把整段重读一遍，越长越贵 |
| `relay_cold` | `80000` | 隔了一个多小时再回来（Claude 的提示缓存已过期，接着说要整段重写）、上下文又有这么长，也提示接力 |
| `reply_language` | `"简体中文"` | 追加给每个对话的固定要求里写的回复语言（“回复一律用……”）。写成 `""` 表示不指定 |
| `extra_instructions` | 空 | **你自己的固定要求**，会追加给每个 Claude 对话（以及 Codex 对话的开场指令）。比如 `"小改动做完直接提交，不用问我。"` 这是你**主动授权**的地方，远窗自己不预先授权任何事 |
| `translate_english` | `false` | **默认关闭**，不会有任何内容被送去翻译。改成 `true` 后，回复里有大段英文（连着 8 个以上英文单词，代码、命令、路径不算）时，先译成中文再给你看，包括网页“工作过程”里的英文思考。优先用 DeepSeek（便宜快，要自己在钥匙串放密钥，见下）；没有密钥就用 Haiku，这会消耗你自己的 Claude 额度。改完重启远窗生效 |

话里说了“用 opus”“深度调到高”就以话里说的为准。

## 安全与整理

| 配置项 | 默认 | 说明 |
|---|---|---|
| `auto_review` | `false` | `false`：危险命令一律等你点“允许”。`true`：先交给另一个 AI 审核员（Sonnet，低档思考）判断，放行或拦下都写进这一轮的报告；它出错或超时才退回来问你 |
| `review_policy` | 空 | 开了 `auto_review` 后，你额外授权审核员放行的事，写成一段话，例如 `"推送到 dev 分支、重启开发用的服务可以放行；推送到 main 一律拦下。"` 审核员默认**不放行推送、上线、部署** |
| `auto_cleanup` | `false` | `true`：远窗每天做一次整理——把 `~/.claude/projects/` 里 **90 天没动**的 Claude 对话记录压缩归档（gzip，能解开）到 `~/.claude/projects-archive/`（远窗里还登记着的对话不动）；把超过 60 天没动、也没有对话在用的临时文件夹挪进废纸篓；**每个月第一次检查时**（刚启用时从下个月开始）自动开一个“清理体检”对话，只列清单，等你点头才把东西挪进废纸篓 |
| `timezone` | 空 | 定时任务用的时区，如 `"Asia/Shanghai"`。空 = 这台电脑当前的时区 |
| `[ext.名字]` | 不写 | 扩展的配置：写了这一节才加载 `src/anzhuo/extensions/名字/`，`enabled = false` 关掉；这一节原样交给扩展。开源版不带任何扩展 |

> `auto_cleanup` 会动 `~/.claude` 里的对话记录位置，所以默认关。对话里的截图和文件副本（`inbox/`、`outbox/`）**任何情况下都不会被自动删除**。

## 钥匙串条目

远窗不把任何密钥写进配置、仓库或日志。macOS 钥匙串里它会用到这些条目（服务名 → 账户）：

| 服务名 | 账户 | 里面是什么 | 怎么放进去 |
|---|---|---|---|
| `anzhuo.web` | 网页账号 | 网页登录密码的 PBKDF2 指纹 | `anzhuo passwd` |
| `anzhuo.dingtalk` | 钉钉 Client ID | 钉钉应用的 Client Secret | `scripts/save_secret.sh` |
| `anzhuo.webpush` | `vapid` | 网页推送的签名私钥 | 第一次用到时自动生成 |
| `anzhuo.deepseek` | `api` | DeepSeek 的 API 密钥（可选：DeepSeek 引擎，以及打开 `translate_english` 后用 DeepSeek 翻译） | `security add-generic-password -U -s anzhuo.deepseek -a api -w`，回车后粘贴 |

## 数据目录里有什么

默认 `~/.local/share/anzhuo/`（`ANZHUO_DATA` 可改）：

| 文件 / 目录 | 内容 |
|---|---|
| `sessions.json` | 对话登记表：编号 ↔ Claude / Codex 的会话 ID ↔ 工作文件夹，以及名字、模型、状态等 |
| `turns/` | 每一轮的记录（说了什么、步骤、改了哪些文件、截图），“完整过程”页和 GPT 对话的历史靠它 |
| `inbox/`、`outbox/` | 你发给它的文件、它交给你的截图和文件的副本。**不会自动删除** |
| `web.json` | 网页登录的设备和会话（Cookie 对应的），权限 600 |
| `push.json` | 手机通知的设备订阅 |
| `schedules.json` | 定时任务 |
| `cards.json` | 钉钉卡片和按钮对应的对话（重启后按钮还能用） |
| `translations.json` | 翻译过的英文片段缓存 |
| `checkpoints/` | Codex 对话的工作文件快照（按内容哈希复用） |
| `recent.jsonl` | 最近 100 条来往原文，**只留在本机**，排查“它为什么这么答”时看 |
| `checkup.json` | 每月体检做到哪个月了（开了 `auto_cleanup` 才有） |

日志在 `~/Library/Logs/anzhuo/`，只记消息类型和长度，不记内容。

## 一份完整的示例

只用网页、放在自己服务器上、让审核员代你放行自己仓库的 dev 分支推送：

```toml
web_base = "https://anzhuo.example.com"
web_port = 8765
watch_host = "my-server"             # ~/.ssh/config 里的主机别名
max_parallel = 4
reply_language = "简体中文"
extra_instructions = "小改动做完后直接 git commit，提交信息用中文，不用问我。"
auto_review = true
review_policy = "推送到 dev 分支可以放行；推送到 main、强制推送一律拦下。"
timezone = "Asia/Shanghai"

[folders]
项目 = "~/Projects/my-app"
笔记 = "~/Documents/notes"
```

## 0.2.0：任务分类与访客账号

`task_grouping = true` 开启自动分类，默认关闭。开启后只发送标题、工作目录末级名称及最多 400 字任务摘要；优先使用钥匙串中的 `anzhuo.deepseek` 密钥，没有密钥或失败时使用 Haiku，会消耗相应额度。分类结果缓存在本机；手动移组优先。同一接力链沿用一个分组。

不配 `accounts` 时沿用原来的 `web_user`。配置多账号时必须有且只有一个 `role = "admin"`；受限账号使用 `role = "user"`，必须设置独立 `root`，可用 `share` 设置其占主账号 Claude 周额度的比例（大于 0、不超过 1，默认 0.2）。分别运行 `scripts/set_account.py 账号名` 设置密码后重启。

受限账号仅支持 macOS，不能使用 Codex；Windows / Linux 的管理员单账号功能保留。目录沙箱、工具路径检查和接口限制均已配置，但本轮没有 Windows 或独立访客设备的实机验证。不要把任意目录共享给不可信的人；管理员仍应按实际用途选择工作目录。

管理页的消耗是已结束轮次估算。新安装不会补造过去的历史，未校准时显示 token；Codex 不折算为 Claude 周额度。`localspend.json` 缓存本机 Claude Code 用量元数据，`usage.jsonl` 保存每轮统计，`task_groups.json` 缓存分类签名与分组名。聊天正文不会作为分类缓存保存。

## 总管（super_agent，默认关闭）

`super_agent = true` 打开后，列表里多一个置顶的“总管”对话。你只跟它说要做什么：

- 它先看有没有正在做同一件事的对话：你明确指着某个对话（编号、“刚才那个”）就把话转过去，否则开一个新对话派活。派活时交出你的原话，不替对话改写成计划。
- 它不亲自干活：总管只拿得到读文件、找文件两类内置工具；改文件、跑命令、上网查、开子助手另有钩子拒掉。
- 结构化汇报：总管派出去的对话每轮结束前用 `report` 汇报 ready / waiting / blocked / failed / dropped，要你拍板时带一个问题。问题一提出就转给总管（不等这一轮结束）；没汇报就想结束的，会被拦一次让它补上；实在没汇报（比如 Codex）才按回复文字判断。
- 退回：派出去的对话收到和它那件事无关的新任务，用 `handback` 退回给总管，总管另开对话或问你，不会再交回给它。
- 直投：在总管里写“#编号 话”，直接交给那个对话，总管不用跑一轮；它做完照样经总管告诉你。
- 你直接在某个对话里说的话：照旧直接通知你，同时给总管记一笔“期间的情况”，总管下次开口前一起看（不为此多跑一轮）。
- 名额：总管有自己的名额，派出去的对话占满 `max_parallel` 时它照样能回答你；你接着跟已有对话说话可以用一个预留名额，新开的活挡不住你。
- 重启：远窗重启时被打断的、总管派出去的活，会带着“先检查做到哪了、别重复做”的提示接着做；总管被打断了会看一眼现状。
- 总管不轮询：派完就结束这一轮，回报会自己来。每次回报总管都会多跑一轮，会多消耗额度。

总管用分工表里简单任务那档的 Claude 型号（那档交给别家时用 Sonnet），固定用 Claude；工作文件夹是数据目录下的 `router/`。关掉开关后总管对话还在列表里，但不再有派活工具和总管约定，派出去的对话也不再回报，预留名额也不启用。

## 别家助手（ACP 引擎，先接 Kimi）

Claude、GPT（Codex）照旧走各自的连接；新加的助手走 ACP（Agent Client Protocol），装好它的命令行就能用，不用改配置：

- **Kimi**：装好 Kimi Code 命令行（`kimi`，能运行 `kimi acp`）并登录。新对话的模型菜单里会多一组“其他助手 · Kimi”；话里写“用 kimi …”也行；总管派活时也能指定 `engine = kimi`。账号的订阅要包含 Kimi Code，不然每轮都会报“Authentication required …”。
- 跑命令要批准时：危险命令（删、推、改库……）照旧交给你点头，其余自动放行一次。
- 和 Claude / GPT 的区别：中途说的话排到下一轮（ACP 不能插话）；不能回退、分叉；查不到额度；远窗的约定放在第一句话前面（ACP 没有系统提示）。
- 要加别的 ACP 助手，在 `src/anzhuo/acp.py` 的 `ENGINES` 里登记启动命令即可。

## DeepSeek 引擎、Codex 选型号

- **DeepSeek**：还是 Claude Code 在干活（工具、交图交文件、步骤清单、回到这里都照旧），只是后端换成 DeepSeek 的 Anthropic 兼容接口。按量计费、很便宜，不占 Claude 的 5 小时和周额度。钥匙串里有 DeepSeek 密钥（和翻译共用那一条）就能用：新对话的模型菜单里多一项“DeepSeek”；话里写“用 deepseek …”也行，“用 deepseek pro”用 `deepseek-v4-pro`（默认 `deepseek-flash`）；总管派活时 `engine = deepseek`。
  - 对话内容会发到 DeepSeek 的服务器：`deepseek_block` 里的文件夹不开 DeepSeek 对话，中途碰到也拒掉；受限账号用不了它。
  - 消耗按 DeepSeek 闲时价估成美元记账（工作日 9–12、14–18 点实际翻倍）；`deepseek-v4-pro` 看不了图。
- **Codex 选型号**：启动时问一次 Codex 能用哪些型号（`model/list`）。话里写“用 gpt luna …”“codex 用 terra …”就用同名型号里最新的那个；总管派活时 `engine = gpt, model = gpt-6-luna` 这样指定。不指定照旧用 `~/.codex/config.toml` 里的。

Codex 在 macOS 上用 ChatGPT 桌面版自带的；其他系统用 PATH 里的 `codex`（`npm i -g @openai/codex`，Windows 上自动找它包里的 `codex.exe`）。
总管派出去的 Codex 对话同样有 `report` / `handback`（通过 Codex 的实验接口 dynamicTools 交给它）；没汇报就想结束的，会接着补一轮只让它补上汇报。

### 总管的名字、分派规则

- **一个账号一个总管**：只有管理员账号有。在列表里把它删了（收起），下次启动会找回原来那个，不会另开一个。
- **名字**：`super_agent_name = "管家"`；网页里给它改名也行（配置里写了的话，重启后以配置为准）。它的自称、转话时“经管家转来”、列表顶上的标题都跟着变。
- **用哪个引擎、哪个模型**：总管的提示里会列出这台电脑上实际能用的引擎和各自的模型（Kimi 的模型列表在远窗启动时探一次，开个空会话看完就删，不花额度）。选法：
  1. 你点名了（“用 kimi”“用 opus”）就照办；
  2. 没点名就照 `super_agent_routing` 里你写的分派规则（一段话，比如“写代码用 claude opus；查资料用 kimi，模型 zhipuai-coding-plan/glm-5.3”）；
  3. 规则也没写到就照分工表（`[split]`）：按任务档位选引擎和模型，首选用不了换备选。
  派完它会告诉你用的是哪个引擎、哪个模型；填了没有的引擎或模型会被拒绝并列出能填的，不会悄悄换。
- 总管自己不答题：知识问答、写东西、出主意也都派出去；它只回答“哪些对话在做什么、做到哪了”。

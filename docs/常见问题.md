# 常见问题

按“现象”找。先跑一遍自检：`.venv/bin/anzhuo check`，多数问题它会直接告诉你。看日志：`~/Library/Logs/anzhuo/err.log`。

## 安装与启动

**`uv sync` 报找不到 Python 3.13**
uv 会自己下载 Python。若公司网络拦了，先用 `uv python install 3.13`（或设置镜像），再重试。

**`anzhuo check` 说“配置：读不到 …”**
还没放配置文件。`mkdir -p ~/.config/anzhuo && cp config.example.toml ~/.config/anzhuo/config.toml`。

**启动时提示“网页还没设登录账号密码”**
运行 `.venv/bin/anzhuo passwd`。没设之前网页谁也登录不了。

**启动报“网页和钉钉都没开，案头没有入口”**
配置里写了 `web = false` 却没配钉钉。去掉 `web = false`，或按 [钉钉接入](钉钉接入.md) 配上钉钉。

**`anzhuo check` 显示 Claude：未登录**
运行 `scripts/claude_login.sh`。案头用的是 SDK 自带的那份 Claude Code，和你终端里平时用的是两份登录状态。

**改了配置没生效**
重启案头：`scripts/install_launchd.sh`（常驻的）或重新 `anzhuo run`。**网页界面**（`app.html`）不用重启，刷新页面就行。

**8765 端口被占用**
配置里改 `web_port`，并同步改 `web_base`（如果你写过）和隧道 / 反向代理指向的端口。

## 登录与访问

**登录一直提示“账号或密码不对”**
账号要和配置里的 `web_user` 一致；忘了密码就重新 `anzhuo passwd`（会覆盖旧的），然后重启案头。

**提示“错太多次了，N 分钟后再试”**
触发了防暴力：同一来源错 5 次锁 15 分钟，所有来源合计 1 小时内错 30 次全体锁 1 小时。等一等，或重启案头（重启会清掉计数）。

**登录后一刷新又要重新登录**
用 `http://` 的远程地址访问时，浏览器会因为 Cookie 的安全限制丢掉登录。外网访问请用 HTTPS，并把 `web_base` 写成 `https://…`。本机的 `http://127.0.0.1:8765` 不受影响。

**手机打不开 / 一直转圈**
- 方案 A（自己的服务器）：电脑睡着或断网时 nginx 会给“电脑那边没连上”的页面；电脑醒着时看隧道：`launchctl list | grep anzhuo.tunnel`，日志 `~/Library/Logs/anzhuo/tunnel.log`。网络断过一下后服务器上可能残留旧隧道占着端口，`scripts/tunnel.sh` 会在重连前自动清理，详见 [外网访问](外网访问.md)。
- 其他方案：确认手机上的 Tailscale / 隧道客户端是连着的。

**页面顶上有一条“连不上”的提示**
电脑睡着了、断网了，或者案头正在更新重启。连上后它会自己消失。

## 干活相关

**新对话提示“没找到文件夹”或“找到好几个”**
网页里手输的是“文件夹名里的几个字”时，案头在 `search_roots` 里按名字找。找不到就写完整路径（如 `~/Projects/demo`）；找到好几个就写得更具体，或写完整路径。

**对话提示“这个文件夹打不开”**
这是 macOS 对“下载 / 桌面 / 文稿”的隐私保护：后台进程没有授权。按 [安装与首次运行 §8](安装与首次运行.md#8-如果你要让它读下载--桌面--文稿里的文件夹) 授权一次。

**它一直停在“等你确认”**
有危险命令在等你点“允许 / 不允许”（网页上对话里和手机通知里都有）。20 分钟没回会当作不允许。不想每次都点，看 [配置参考](配置参考.md#安全与整理) 的 `auto_review`。

**撞到额度了怎么办**
列表里会写“额度用完 · 17:40 恢复”，恢复后一分钟自动替你说一句“继续”。不想自动接，在那个对话里点“别自动接”。

**选了 GPT（Codex）却报“没找到 ChatGPT 桌面版自带的 Codex”**
需要安装 ChatGPT 桌面版并登录，且位于 `/Applications/ChatGPT.app`。

**回复里还是出现一大段英文**
翻译默认是关闭的（`translate_english = false`），所以英文会原样显示。想看中文，把配置里的 `translate_english` 改成 `true` 并重启案头：会把连续 8 个以上英文单词的段落译成中文，代码、命令、路径不翻。有 DeepSeek 密钥就用它，没有就用 Haiku（消耗你自己的 Claude 额度）。

**它自己提交 / 推送了，我没让它做**
案头内置的约定里没有任何提交、推送的授权。检查两处：你的 `extra_instructions` 里是不是写了；你项目里的 `CLAUDE.md` / 全局 `~/.claude/CLAUDE.md` 是不是写了——案头的对话会加载你的用户、项目、本地三层 Claude Code 设置，所以各项目的规则照常生效。

## 手机通知

**侧栏没有“开启手机通知”**
需要同时满足：用 HTTPS 访问；iOS / iPadOS 16.4 以上；**从主屏幕图标打开**（不是 Safari 标签页）；浏览器支持 Web Push。

**点了授权还是收不到**
- 你正开着那个对话看时不会通知（这是设计）；
- 看“⋯ → 登录的设备”里这台设备还在；
- 重新“添加到主屏幕”一次，再点“开启手机通知”。

## 数据与清理

**对话记录存在哪？想备份**
对话内容在 Claude Code / Codex 自己的目录（`~/.claude`、`~/.codex`）；案头自己的登记表和每轮记录在 `~/.local/share/anzhuo/`。备份这两处即可。

**“删除对话”是真删吗**
不是，只是收起：聊天记录和附件都还在，30 天内在搜索里点一下找回。

**`~/.claude/projects` 里的旧对话记录被移走了**
你开了 `auto_cleanup = true`：它会把 90 天没动的记录压缩归档到 `~/.claude/projects-archive/`（gzip，能解开）。想关就设成 `false`。默认是关的。

## 还是不行

带上 `anzhuo check` 的输出和 `err.log` 里相关的几行，到仓库提 issue。**先把里面的个人信息（路径里的用户名、域名、IP）打码。**
